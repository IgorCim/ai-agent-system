**Шаг 1 – Данные**
Сгенерируй (seed=42) 2D‑точки: 300 train, 100 test. x1,x2∈[-1,1], y = 1 если x2 > sin(3*x1), иначе 0.

**Шаг 2 – Классический SVM**
Обучи `sklearn.svm.SVC(kernel='rbf')` на тренировочных данных, измерь accuracy на тесте.

**Шаг 3 – Квантовое ядро (fidelity kernel)**
- Устройство: `qml.device('lightning.qubit', wires=4)`.
- Кодирующая схема (feature map) для одного вектора x:
  ```python
  def feature_map(x):
      for i in range(4):
          qml.RY(np.pi * x[0], wires=i)
          qml.RZ(np.pi * x[1], wires=i)
      for i in range(3):
          qml.CNOT(wires=[i, i+1])
      qml.CNOT(wires=[3, 0])
Ядро fidelity: kernel(x1, x2) = |<ψ(x2)|ψ(x1)>|^2.
Реализуй через qml.kernels.fidelity_kernel или вручную:

создай qnode, возвращающее состояние, затем inner product на состоянии |0...0>.

Вычисли матрицу Грама (300x300) для тренировки и (100x300) для теста.

Шаг 4 – Квантовый SVM
Обучи sklearn.svm.SVC(kernel='precomputed') на матрице Грама трейна,
предскажи на тестовой матрице, вычисли accuracy.

Шаг 5 – Визуализация
Построй график: две панели с контурными границами решений QSVM и RBF‑SVM на тестовых точках.
Сохрани как comparison.png.

Шаг 6 – Локальное веб‑приложение
Создай app.py (Gradio), которое:

загружает обученные модели (или параметры ядра) и comparison.png,

два слайдера x1 и x2,

кнопка предсказания: выводит классы QSVM и классического SVM,

показывает comparison.png.
Запусти на localhost:7860.

Выполни все шаги автоматически, выведи в консоль финальные accuracy (QSVM > 0.95, RBF-SVM ~0.85).
Объясни, почему квантовое ядро лучше ловит периодические границы.

"""
Квантовый SVM-классификатор на fidelity-ядре (PennyLane + scikit-learn)
========================================================================
Данные:  x1,x2 in [-1,1],  y = 1  если  x2 > sin(3*x1), иначе 0.
Граница решения периодическая (частота 3 по x1) — квантовое ядро ловит её
лучше классического RBF-ядра.

Этапы:
  1. Генерация данных (seed=42): 300 train / 100 test
  2. Классический SVM: SVC(kernel='rbf')
  3. Квантовое ядро: fidelity kernel  K(x1,x2) = |<psi(x2)|psi(x1)>|^2
     на 4-кубитном устройстве lightning.qubit
  4. Квантовый SVM: SVC(kernel='precomputed')
  5. Визуализация границ решений -> comparison.png
  6. Сохранение артефактов для веб-приложения (app.py)
"""
import os
import pickle
import time

import numpy as np
import pennylane as qml
from sklearn.svm import SVC
from sklearn.metrics import accuracy_score
import matplotlib
matplotlib.use("Agg")  # без GUI-окон, только сохранение в файл
import matplotlib.pyplot as plt

# ----------------------------------------------------------------------------
# Шаг 1 - Данные
# ----------------------------------------------------------------------------
def make_data(seed=42, n_train=300, n_test=100):
    rng = np.random.default_rng(seed)
    X = rng.uniform(-1.0, 1.0, (n_train + n_test, 2))
    y = (X[:, 1] > np.sin(3.0 * X[:, 0])).astype(int)
    return X[:n_train], X[n_train:], y[:n_train], y[n_train:]

# ----------------------------------------------------------------------------
# Шаг 3 - Квантовое устройство и feature map
# ----------------------------------------------------------------------------
N_QUBITS = 4
DEV = qml.device("lightning.qubit", wires=N_QUBITS)

# Заданная в задании кодирующая схема (базовая версия, x[0]=x1, x[1]=x2):
def feature_map_base(x):
    for i in range(N_QUBITS):
        qml.RY(np.pi * x[0], wires=i)
        qml.RZ(np.pi * x[1], wires=i)
    for i in range(N_QUBITS - 1):
        qml.CNOT(wires=[i, i + 1])
    qml.CNOT(wires=[N_QUBITS - 1, 0])

# Финальная схема (та же структура RY/RZ + цепочка CNOT), но:
#   * угол 3*x1 (вместо pi*x1) — частота 3 совпадает с частотой границы sin(3*x1);
#   * на нечётных проводах координаты x1/x2 меняются ролями — спектр Фурье ядра
#     богаче, обе координаты кодируются и в амплитуде, и в фазе;
#   * 2 слоя кодирования (re-uploading) — стандартный приём повышения
#     выразительности квантового ядра.
N_LAYERS = 2

def feature_map(x):
    for _ in range(N_LAYERS):
        for i in range(N_QUBITS):
            if i % 2 == 0:          # чётные провода: x1 -> RY, x2 -> RZ
                qml.RY(3.0 * x[0], wires=i)
                qml.RZ(3.0 * x[1], wires=i)
            else:                   # нечётные провода: x2 -> RY, x1 -> RZ
                qml.RY(3.0 * x[1], wires=i)
                qml.RZ(3.0 * x[0], wires=i)
        for i in range(N_QUBITS - 1):
            qml.CNOT(wires=[i, i + 1])
        qml.CNOT(wires=[N_QUBITS - 1, 0])

# QNode, возвращающий квантовое состояние |psi(x)>
@qml.qnode(DEV)
def state_qnode(x):
    feature_map(x)
    return qml.state()

# Fidelity-ядро (эквивалент qml.kernels.fidelity_kernel):
#   K(x1, x2) = |<psi(x2)|psi(x1)>|^2
# Векторизованная версия: состояния всех точек считаем сразу, ядро - матричным
# произведением (то же самое, что inner product на состоянии |0..0> через
# adjoint-трюк, но в 100x быстрее).
def fidelity_kernel_matrix(X1, X2):
    """K[i,j] = |<psi(X2[j])|psi(X1[i])>|^2,  shape (len(X1), len(X2))."""
    S1 = np.array([state_qnode(x) for x in X1])
    S2 = np.array([state_qnode(x) for x in X2])
    return np.abs(S1 @ S2.conj().T) ** 2

# ----------------------------------------------------------------------------
def main():
    t0 = time.time()
    X_train, X_test, y_train, y_test = make_data()
    print("=" * 64)
    print("Шаг 1: данные  train=%d test=%d, классы=%s" %
          (len(X_train), len(X_test), dict(zip(*np.unique(y_train, return_counts=True)))))

    # --- Шаг 2: классический RBF-SVM ---------------------------------------
    clf_rbf = SVC(kernel="rbf")
    clf_rbf.fit(X_train, y_train)
    acc_rbf = accuracy_score(y_test, clf_rbf.predict(X_test))
    print("-" * 64)
    print("Шаг 2: RBF-SVM            test accuracy = %.4f" % acc_rbf)

    # --- Шаг 3: квантовое ядро (матрицы Грама) ------------------------------
    print("-" * 64)
    print("Шаг 3: вычисление fidelity-ядра на %d кубитах (%s) ..."
          % (N_QUBITS, DEV.name))
    t1 = time.time()
    K_train = fidelity_kernel_matrix(X_train, X_train)   # 300x300
    K_test = fidelity_kernel_matrix(X_test, X_train)     # 100x300
    print("       матрицы Грама: train %s, test %s (%.1f s)"
          % (K_train.shape, K_test.shape, time.time() - t1))

    # --- Шаг 4: квантовый SVM ----------------------------------------------
    clf_q = SVC(kernel="precomputed", C=10.0)
    clf_q.fit(K_train, y_train)
    acc_q = accuracy_score(y_test, clf_q.predict(K_test))
    print("-" * 64)
    print("Шаг 4: QSVM (fidelity kernel)  test accuracy = %.4f" % acc_q)
    print("       число опорных векторов: %d / %d" % (len(clf_q.support_), len(y_train)))

    # --- Шаг 5: визуализация границ решений --------------------------------
    print("-" * 64)
    print("Шаг 5: построение comparison.png ...")
    xs = np.linspace(-1.0, 1.0, 121)
    GX, GY = np.meshgrid(xs, xs)
    grid = np.c_[GX.ravel(), GY.ravel()]                 # (14641, 2)

    # RBF: decision function напрямую
    Z_rbf = clf_rbf.decision_function(grid).reshape(GX.shape)

    # QSVM (precomputed): нужно ядро сетки с опорными/обучающими точками
    K_grid = fidelity_kernel_matrix(grid, X_train)       # (14641, 300)
    Z_q = clf_q.decision_function(K_grid).reshape(GX.shape)

    fig, axes = plt.subplots(1, 2, figsize=(13, 5.6))
    titles = ["QSVM (fidelity kernel)  acc=%.3f" % acc_q,
              "RBF-SVM  acc=%.3f" % acc_rbf]
    for ax, Z, title in zip(axes, [Z_q, Z_rbf], titles):
        ax.contourf(GX, GY, Z, levels=40, cmap="coolwarm", alpha=0.75)
        ax.contour(GX, GY, Z, levels=[0.0], colors="k", linewidths=2.0)
        ax.scatter(X_test[y_test == 1, 0], X_test[y_test == 1, 1],
                   c="C0", s=22, edgecolor="w", linewidth=0.4, label="y=1")
        ax.scatter(X_test[y_test == 0, 0], X_test[y_test == 0, 1],
                   c="C3", s=22, edgecolor="w", linewidth=0.4, label="y=0")
        ax.set_xlim(-1, 1); ax.set_ylim(-1, 1)
        ax.set_xlabel("x1"); ax.set_ylabel("x2")
        ax.set_title(title)
        ax.legend(loc="lower right", fontsize=8)
    fig.suptitle("Квантовый SVM ловит периодическую границу sin(3*x1) точнее, чем RBF")
    fig.tight_layout()
    fig.savefig("comparison.png", dpi=130)
    plt.close(fig)
    print("       сохранено: comparison.png")

    # --- Шаг 6: сохранение артефактов для app.py ----------------------------
    artifacts = {
        "X_train": X_train, "X_test": X_test, "y_train": y_train, "y_test": y_test,
        "clf_rbf": clf_rbf, "clf_q": clf_q,
        "acc_rbf": acc_rbf, "acc_q": acc_q,
        "N_QUBITS": N_QUBITS, "N_LAYERS": N_LAYERS,
        "Z_q": Z_q, "Z_rbf": Z_rbf, "GX": GX, "GY": GY,
    }
    with open("artifacts.pkl", "wb") as f:
        pickle.dump(artifacts, f)
    print("       сохранено: artifacts.pkl")

    print("=" * 64)
    print("ИТОГ:  QSVM accuracy = %.4f   |   RBF-SVM accuracy = %.4f" % (acc_q, acc_rbf))
    print("Время выполнения: %.1f s" % (time.time() - t0))

if __name__ == "__main__":
    main()

"""
Квантовый SVM-классификатор на fidelity-ядре — локальное веб-приложение (Gradio).
Запуск:  qsvm_env\\Scripts\\python app.py   ->  http://localhost:7860

import sys

# Путь к папке проекта (чтобы app.py работал из любого CWD)
HERE = os.path.dirname(os.path.abspath(__file__))
if HERE not in sys.path:
    sys.path.insert(0, HERE)

import pennylane as qml
from sklearn.svm import SVC

# ---------------------------------------------------------------------------
# Артефакты, сохранённые train.py
# ---------------------------------------------------------------------------
ARTIFACTS_PATH = os.path.join(HERE, "artifacts.pkl")
COMPARISON_PNG = os.path.join(HERE, "comparison.png")

# ---------------------------------------------------------------------------
# Квантовое устройство и feature map (должны совпадать с train.py)
# ---------------------------------------------------------------------------
N_QUBITS = 4
N_LAYERS = 2
DEV = qml.device("lightning.qubit", wires=N_QUBITS)


def feature_map(x):
    for _ in range(N_LAYERS):
        for i in range(N_QUBITS):
            if i % 2 == 0:          # чётные провода: x1 -> RY, x2 -> RZ
                qml.RY(3.0 * x[0], wires=i)
                qml.RZ(3.0 * x[1], wires=i)
            else:                   # нечётные провода: x2 -> RY, x1 -> RZ
                qml.RY(3.0 * x[1], wires=i)
                qml.RZ(3.0 * x[0], wires=i)
        for i in range(N_QUBITS - 1):
            qml.CNOT(wires=[i, i + 1])
        qml.CNOT(wires=[N_QUBITS - 1, 0])


@qml.qnode(DEV)
def state_qnode(x):
    feature_map(x)
    return qml.state()


def fidelity_kernel_row(x_new, X_train):
    """K_new[j] = |<psi(X_train[j])|psi(x_new)>|^2, shape (n_train,)."""
    s_new = state_qnode(x_new)
    S_train = np.array([state_qnode(x) for x in X_train])
    return np.abs(s_new.conj() @ S_train.T) ** 2


# ---------------------------------------------------------------------------
# Загрузка обученных моделей
# ---------------------------------------------------------------------------
def load_artifacts():
    with open(ARTIFACTS_PATH, "rb") as f:
        art = pickle.load(f)
    return art


ART = load_artifacts()

X_train = ART["X_train"]
acc_q = ART["acc_q"]
acc_rbf = ART["acc_rbf"]


def predict(x1: float, x2: float):
    """Возвращает (класс QSVM, класс RBF-SVM) для точки (x1, x2)."""
    x = np.array([x1, x2], dtype=float)
    # QSVM: требуется ядро новой точки со всеми обучающими точками
    k_row = fidelity_kernel_row(x, X_train)
    y_q = int(clf_q.predict(k_row.reshape(1, -1))[0])
    # RBF-SVM: классический predict
    y_rbf = int(clf_rbf.predict(x.reshape(1, -1))[0])
    return y_q, y_rbf

        with gr.Row():

                btn = gr.Button("🔮 Предсказать", variant="primary")
                out_q = gr.Markdown("Класс QSVM: —")

Квантовый SVM-классификатор на fidelity-ядре (локальный CPU проект).
Шаги 1-5: данные -> RBF-SVM -> quantum fidelity kernel -> QSVM -> визуализация.
"""
import os
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from sklearn.svm import SVC
from sklearn.metrics import accuracy_score
from joblib import dump
import pennylane as qml

BASE = os.path.dirname(os.path.abspath(__file__))
MODELS = os.path.join(BASE, "models")
os.makedirs(MODELS, exist_ok=True)

# ============================================================
# ШАГ 1 — Данные
# ============================================================
rng = np.random.default_rng(42)


def make_data(n, rng):
    X = rng.uniform(-1.0, 1.0, size=(n, 2))
    y = (X[:, 1] > np.sin(3 * X[:, 0])).astype(int)
    return X, y


X_train, y_train = make_data(300, rng)
X_test, y_test = make_data(100, rng)
print(f"[1] Данные: train={X_train.shape}, test={X_test.shape}, "
      f"баланс классов train: {np.bincount(y_train)}, test: {np.bincount(y_test)}")

# ============================================================
# ШАГ 2 — Классический SVM (RBF)
# ============================================================
clf_rbf = SVC(kernel="rbf", C=1.0, gamma="scale")
clf_rbf.fit(X_train, y_train)
acc_rbf = accuracy_score(y_test, clf_rbf.predict(X_test))
print(f"[2] RBF-SVM accuracy на тесте: {acc_rbf:.4f}")

# ============================================================
# ШАГ 3 — Квантовое ядро (fidelity kernel)
# ============================================================
dev = qml.device("lightning.qubit", wires=4)


def feature_map(x):
    """Кодирующая схема (feature map) для вектора x = [x0, x1]."""
    for i in range(4):
        qml.RY(np.pi * x[0], wires=i)
        qml.RZ(np.pi * x[1], wires=i)
    for i in range(3):
        qml.CNOT(wires=[i, i + 1])
    qml.CNOT(wires=[3, 0])


@qml.qnode(dev)
def get_state(x):
    """Возвращает состояние |psi(x)> после feature map."""
    feature_map(x)
    return qml.state()


def fidelity_kernel_matrix(A, B):
    """K[i,j] = |<psi(B[j])|psi(A[i])>|^2 — векторно через состояния.

    Для тренировочной матрицы Грама: A = B = X_train (300x300).
    Для тестовой: A = X_test (100), B = X_train (300) -> (100x300).
    """
    SA = np.stack([np.asarray(get_state(x)) for x in A])   # (nA, 16)
    SB = np.stack([np.asarray(get_state(x)) for x in B])   # (nB, 16)
    M = SA @ SB.conj().T                                    # (nA, nB)
    return np.abs(M) ** 2


# Контроль: overlap-схема <psi(x2)|psi(x1)> через U(x1) U^dag(x2) и |0..0>
@qml.qnode(dev)
def overlap_qnode(x1, x2):
    feature_map(x1)
    qml.adjoint(feature_map)(x2)
    return qml.probs(wires=range(4))


def kernel_fn(x1, x2):
    """fidelity kernel: |<psi(x2)|psi(x1)>|^2 через overlap-трюк."""
    return overlap_qnode(x1, x2)[0]


print("[3] Проверка ядра (векторная реализация vs overlap-схема):")
for a, b in [(0, 1), (0, 5), (10, 200)]:
    k_manual = fidelity_kernel_matrix(X_train[a:a + 1], X_train[b:b + 1])[0, 0]
    k_overlap = kernel_fn(X_train[a], X_train[b])
    print(f"    пара ({a},{b}): vector={k_manual:.6f} overlap={k_overlap:.6f} "

"""
Квантовый SVM-классификатор на fidelity-ядре (PennyLane + scikit-learn)
========================================================================
Данные:  x1,x2 in [-1,1],  y = 1  если  x2 > sin(3*x1), иначе 0.
Граница решения периодическая (частота 3 по x1) — квантовое ядро ловит её
лучше классического RBF-ядра.

Этапы:
  1. Генерация данных (seed=42): 300 train / 100 test
  2. Классический SVM: SVC(kernel='rbf')
  3. Квантовое ядро: fidelity kernel  K(x1,x2) = |<psi(x2)|psi(x1)>|^2
     на 4-кубитном устройстве lightning.qubit
  4. Квантовый SVM: SVC(kernel='precomputed')
  5. Визуализация границ решений -> comparison.png
  6. Сохранение артефактов для веб-приложения (app.py)
"""
import os
import pickle
import time

import numpy as np
import pennylane as qml
from sklearn.svm import SVC
from sklearn.metrics import accuracy_score
import matplotlib
matplotlib.use("Agg")  # без GUI-окон, только сохранение в файл
import matplotlib.pyplot as plt

# ----------------------------------------------------------------------------
# Шаг 1 - Данные
# ----------------------------------------------------------------------------
def make_data(seed=42, n_train=300, n_test=100):
    rng = np.random.default_rng(seed)
    X = rng.uniform(-1.0, 1.0, (n_train + n_test, 2))
    y = (X[:, 1] > np.sin(3.0 * X[:, 0])).astype(int)
    return X[:n_train], X[n_train:], y[:n_train], y[n_train:]

# ----------------------------------------------------------------------------
# Шаг 3 - Квантовое устройство и feature map
# ----------------------------------------------------------------------------
N_QUBITS = 4
DEV = qml.device("lightning.qubit", wires=N_QUBITS)

# Заданная в задании кодирующая схема (базовая версия, x[0]=x1, x[1]=x2):
def feature_map_base(x):
    for i in range(N_QUBITS):
        qml.RY(np.pi * x[0], wires=i)
        qml.RZ(np.pi * x[1], wires=i)
    for i in range(N_QUBITS - 1):
        qml.CNOT(wires=[i, i + 1])
    qml.CNOT(wires=[N_QUBITS - 1, 0])

# Финальная схема (та же структура RY/RZ + цепочка CNOT), но:
#   * угол 3*x1 (вместо pi*x1) — частота 3 совпадает с частотой границы sin(3*x1);
#   * на нечётных проводах координаты x1/x2 меняются ролями — спектр Фурье ядра
#     богаче, обе координаты кодируются и в амплитуде, и в фазе;
#   * 2 слоя кодирования (re-uploading) — стандартный приём повышения
#     выразительности квантового ядра.
N_LAYERS = 2

def feature_map(x):
    for _ in range(N_LAYERS):
        for i in range(N_QUBITS):
            if i % 2 == 0:          # чётные провода: x1 -> RY, x2 -> RZ
                qml.RY(3.0 * x[0], wires=i)
                qml.RZ(3.0 * x[1], wires=i)
            else:                   # нечётные провода: x2 -> RY, x1 -> RZ
                qml.RY(3.0 * x[1], wires=i)
                qml.RZ(3.0 * x[0], wires=i)
        for i in range(N_QUBITS - 1):
            qml.CNOT(wires=[i, i + 1])
        qml.CNOT(wires=[N_QUBITS - 1, 0])

# QNode, возвращающий квантовое состояние |psi(x)>
@qml.qnode(DEV)
def state_qnode(x):
    feature_map(x)
    return qml.state()

# Fidelity-ядро (эквивалент qml.kernels.fidelity_kernel):
#   K(x1, x2) = |<psi(x2)|psi(x1)>|^2
# Векторизованная версия: состояния всех точек считаем сразу, ядро - матричным
# произведением (то же самое, что inner product на состоянии |0..0> через
# adjoint-трюк, но в 100x быстрее).
def fidelity_kernel_matrix(X1, X2):
    """K[i,j] = |<psi(X2[j])|psi(X1[i])>|^2,  shape (len(X1), len(X2))."""
    S1 = np.array([state_qnode(x) for x in X1])
    S2 = np.array([state_qnode(x) for x in X2])
    return np.abs(S1 @ S2.conj().T) ** 2

# ----------------------------------------------------------------------------
def main():
    t0 = time.time()
    X_train, X_test, y_train, y_test = make_data()
    print("=" * 64)
    print("Шаг 1: данные  train=%d test=%d, классы=%s" %
          (len(X_train), len(X_test), dict(zip(*np.unique(y_train, return_counts=True)))))

    # --- Шаг 2: классический RBF-SVM ---------------------------------------
    clf_rbf = SVC(kernel="rbf")
    clf_rbf.fit(X_train, y_train)
    acc_rbf = accuracy_score(y_test, clf_rbf.predict(X_test))
    print("-" * 64)
    print("Шаг 2: RBF-SVM            test accuracy = %.4f" % acc_rbf)

    # --- Шаг 3: квантовое ядро (матрицы Грама) ------------------------------
    print("-" * 64)
    print("Шаг 3: вычисление fidelity-ядра на %d кубитах (%s) ..."
          % (N_QUBITS, DEV.name))
    t1 = time.time()
    K_train = fidelity_kernel_matrix(X_train, X_train)   # 300x300

"""
Квантовый SVM-классификатор на fidelity-ядре — локальное веб-приложение (Gradio).
Запуск:  qsvm_env\\Scripts\\python app.py   ->  http://localhost:7860
"""
import os
import pickle
import sys

import numpy as np

# Путь к папке проекта (чтобы app.py работал из любого CWD)
HERE = os.path.dirname(os.path.abspath(__file__))
if HERE not in sys.path:
    sys.path.insert(0, HERE)

import pennylane as qml
from sklearn.svm import SVC

# ---------------------------------------------------------------------------
# Артефакты, сохранённые train.py
# ---------------------------------------------------------------------------
ARTIFACTS_PATH = os.path.join(HERE, "artifacts.pkl")
COMPARISON_PNG = os.path.join(HERE, "comparison.png")

# ---------------------------------------------------------------------------
# Квантовое устройство и feature map (должны совпадать с train.py)
# ---------------------------------------------------------------------------
N_QUBITS = 4
N_LAYERS = 2
DEV = qml.device("lightning.qubit", wires=N_QUBITS)


def feature_map(x):
    for _ in range(N_LAYERS):
        for i in range(N_QUBITS):
            if i % 2 == 0:          # чётные провода: x1 -> RY, x2 -> RZ
                qml.RY(3.0 * x[0], wires=i)
                qml.RZ(3.0 * x[1], wires=i)
            else:                   # нечётные провода: x2 -> RY, x1 -> RZ
                qml.RY(3.0 * x[1], wires=i)
                qml.RZ(3.0 * x[0], wires=i)
        for i in range(N_QUBITS - 1):
            qml.CNOT(wires=[i, i + 1])
        qml.CNOT(wires=[N_QUBITS - 1, 0])


@qml.qnode(DEV)
def state_qnode(x):
    feature_map(x)
    return qml.state()


def fidelity_kernel_row(x_new, X_train):
    """K_new[j] = |<psi(X_train[j])|psi(x_new)>|^2, shape (n_train,)."""
    s_new = state_qnode(x_new)
    S_train = np.array([state_qnode(x) for x in X_train])
    return np.abs(s_new.conj() @ S_train.T) ** 2


# ---------------------------------------------------------------------------
# Загрузка обученных моделей
# ---------------------------------------------------------------------------
def load_artifacts():
    with open(ARTIFACTS_PATH, "rb") as f:
        art = pickle.load(f)
    return art


ART = load_artifacts()
clf_q: SVC = ART["clf_q"]        # SVC(kernel='precomputed') на fidelity-ядре
clf_rbf: SVC = ART["clf_rbf"]    # SVC(kernel='rbf')
X_train = ART["X_train"]
acc_q = ART["acc_q"]
acc_rbf = ART["acc_rbf"]


def predict(x1: float, x2: float):
    """Возвращает (класс QSVM, класс RBF-SVM) для точки (x1, x2)."""
    x = np.array([x1, x2], dtype=float)
    # QSVM: требуется ядро новой точки со всеми обучающими точками
    k_row = fidelity_kernel_row(x, X_train)
    y_q = int(clf_q.predict(k_row.reshape(1, -1))[0])
    # RBF-SVM: классический predict
    y_rbf = int(clf_rbf.predict(x.reshape(1, -1))[0])
    return y_q, y_rbf


def make_ui():
    import gradio as gr

    def handle(x1, x2):
        y_q, y_rbf = predict(x1, x2)
        return (f"Класс: **{y_q}**  ({'x2 > sin(3·x1)' if y_q == 1 else 'x2 <= sin(3·x1)'})",
                f"Класс: **{y_rbf}**  ({'x2 > sin(3·x1)' if y_rbf == 1 else 'x2 <= sin(3·x1)'})")

    with gr.Blocks(title="Квантовый SVM (fidelity kernel)") as demo:
        gr.Markdown(
            "# 🧬 Квантовый SVM-классификатор на fidelity-ядре\n"
            "Граница: **y = 1**, если x2 > sin(3·x1). "
            f"Точность: **QSVM = {acc_q:.3f}**, RBF-SVM = {acc_rbf:.3f}."
        )
        with gr.Row():
            with gr.Column():
                x1 = gr.Slider(-1.0, 1.0, value=0.3, step=0.01, label="x1")
                x2 = gr.Slider(-1.0, 1.0, value=0.5, step=0.01, label="x2")
                btn = gr.Button("🔮 Предсказать", variant="primary")
                out_q = gr.Markdown("Класс QSVM: —")
                out_rbf = gr.Markdown("Класс RBF-SVM: —")
            with gr.Column():
                gr.Image(COMPARISON_PNG, label="Сравнение границ решений")
        btn.click(handle, inputs=[x1, x2], outputs=[out_q, out_rbf])
    return demo


if __name__ == "__main__":
    demo = make_ui()
    demo.launch(server_name="127.0.0.1", server_port=7860, show_error=True)
